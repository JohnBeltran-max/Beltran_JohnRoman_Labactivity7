# Beltran_JohnRoman_Labactivity7

Step 1: Install Required Libraries
Open your project folder in VS Code, open the terminal, and install the required dependencies by running:

PowerShell
python -m pip install requests matplotlib
Step 2: Execute the Script
Run the script using the relative path in your terminal:

PowerShell
python .\labactivity7.py
Step 3: View Test Cases
As each chart window pops up for Manila, Cebu City, and Davao City, close the window to allow the script to proceed automatically to the next location.

Step 4: Collect Evidence
Locate the automatically generated image files (test_case_1_manila.png, test_case_2_cebu_city.png, test_case_3_davao_city.png) and your terminal text logs to include as your final lab submission proof.
